A small Rust calculator that runs in the browser with WebAssembly.

This site is static, but the calculator below runs Rust in your browser, compiled to WebAssembly (WASM). It is made with egui. Press Load demo to start it.

How it works

The demo is a Rust crate that Trunk compiles before Zola builds the site. A shortcode embeds it in an iframe, which loads nothing until you press the button.
