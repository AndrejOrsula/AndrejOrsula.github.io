Space Robotics Bench

    Andrej Orsula
  • Oct 2024
  • •Tags: 
  • space-robotics, 
  • simulation

An open-source simulation framework and benchmark for robot learning in space, with procedurally generated environments, built on NVIDIA Isaac Sim.

Space Robotics Bench is an open-source simulation framework for robot learning in space. Built on NVIDIA Isaac Sim, it combines on-demand procedural generation and domain randomization with massively parallel simulation, and its benchmark tasks cover manipulation, mobile robotics and mobile manipulation on the Moon, Mars and asteroids and in orbit. A Gymnasium API connects it to standard robot-learning frameworks, and a ROS 2 interface to the ROS 2 and Space ROS ecosystems.
